# Preview notes

The V8 stand-alone HTML preview was removed because it does not run the V9 Tailwind/Vite pipeline and would show outdated markup.

To preview the actual V9 source (including Tailwind-generated utilities), open a terminal in the project root and run `pnpm install` followed by `pnpm dev`.

The V8 3D/LED visual effects are retained in source; V9 refactors selected grids, controls, cards and Admin dashboard styles into Tailwind utilities.
